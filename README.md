# Sales-Forecasting-for-Retail-Business-Using-XGBoost-Algorithm
Daily sales forecasting using XGBoost – 29–35% more accurate than monthly baselines. Trained on 5 years real retail data (805 stores, 3,988 products). MAE 2.84, RMSE 4.12, R² 0.91. Fully client-side web app (XGBoost WebAssembly): upload CSV → instant private forecasts.
